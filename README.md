# 📡 RAG-Based Future-Ready Telecom Radio Access Network (RAN) AI Assistant

## 🚀 Project Overview

An AI-powered Telecom RAN Assistant that combines dynamic network simulation, intelligent anomaly detection, rule-based Root Cause Analysis (RCA), network optimization and Retrieval-Augmented Generation (RAG).

The system aims to help understand telecom network issues, investigate potential root causes, recommend corrective actions and generate evidence-based technical explanations using Qwen 2.5.

### 🎯 Key Objectives

- Simulate dynamic telecom network conditions.
- Monitor KPIs and detect network anomalies.
- Identify potential root causes using rule-based RCA.
- Recommend network optimization strategies.
- Retrieve telecom knowledge from domain-specific datasets and 3GPP specifications.
- Generate contextual explanations using RAG and Qwen 2.5.
- Visualize network insights through an interactive Streamlit dashboard.

### 🧠 Core Modules

| Module | Description |
|---|---|
| Network Simulation | Simulates telecom towers, events and KPIs |
| Anomaly Detection | Identifies abnormal network behaviour |
| Rule-Based RCA | Investigates potential network root causes |
| Optimization Engine | Recommends corrective actions |
| RAG Pipeline | Retrieves relevant telecom knowledge |
| Qwen 2.5 | Generates contextual explanations |
| Streamlit Dashboard | Visualizes network insights and AI responses |

### 📚 Knowledge Sources

- **TeleQnA:** Telecom question-answering dataset.
- **ORANBench:** O-RAN knowledge and benchmark data.
- **TeleLogs:** Telecom network logs and incident information.
- **3GPP:** Telecom technical specifications.

### 🛠️ Technology Stack

Python | Pandas | NumPy | Qwen 2.5 | Qdrant | BGE Embeddings | PyTorch | Hugging Face Transformers | Streamlit | Plotly

### 📊 Implementation Highlights

- 29,791 telecom knowledge vectors indexed in Qdrant.
- 384-dimensional BGE embeddings.
- Semantic retrieval tested across telecom queries.
- Simulation tested with 10 towers and multiple anomalies.
- Rule-based RCA and evidence collection validated.
- Network optimization recommendations tested.
